# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private reporting:
**Security tab → Report a vulnerability** on this repository. Include the platform, the app
version, and steps to reproduce.

## Scope

This repository is the Vispar client (Android, Android TV, iOS, web and desktop). Reports about
the client are in scope: for example a way to run code through a crafted subtitle or description,
leaking stored data, or unsafe handling of the update download.

The API proxy and server are private and hosted separately. If you find a problem that involves
them, report it the same way and it will be passed on.
